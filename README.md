🩺 MediMind AI Pro
Advanced Symptom-Based Disease Analysis & Health Assistant

MediMind AI Pro is an intelligent health assistant web application built using Streamlit that helps users analyze possible diseases based on symptoms and provides commonly used medications. It also includes an interactive chatbot for a more natural, conversational health guidance experience.

⚠️ Disclaimer: This application is for educational and informational purposes only. It does not replace professional medical advice.



🚀 FEATURES

🔍 Symptom-Based Disease Detection
Select a symptom and instantly view possible related diseases with recommended medications.

💬 AI-Style Health Chatbot
Chat naturally with the assistant to describe symptoms and receive intelligent responses.

🎨 Premium Medical UI
Modern red-gradient UI with glassmorphism effects for a professional healthcare look.

⚡ Fast & Lightweight
Uses CSV-based data storage with Streamlit caching for quick performance.

🧠 Beginner-Friendly Logic
Easy-to-understand Python logic without heavy ML dependencies.

▶️ How to Run Locally

1.Clone the repository

  git clone https://github.com/your-username/MediMind-AI-Pro.git

2.Install dependencies

  pip install -r requirements.txt

3.Run the application

  streamlit run App.py


  📊 Dataset

The dataset.csv file contains:

-Disease name

-Symptoms

-Common medications

The system matches user input symptoms with this dataset to provide results.
